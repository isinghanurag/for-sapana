# 🏔️ Our Love Story

A mountain-themed love story website: dawn over layered snow-capped peaks with drifting fog and pine forests, a cosy log-cabin photo wall, gentle snowfall, background music and a mountain-postcard love letter.

Pure HTML/CSS/JS. No build step and no dependencies.

## Make it yours

1. Edit **`content.js`**: names, dates, moments, cute behaviours and the letter.
2. Put photos in `assets/photos/` and reference them, e.g. `photo: "assets/photos/first-date.jpg"`.
3. `cuteWall` is the hanging photo wall. Add `photo` (and an optional `caption`) for each frame.
4. Shayari pictures go in `shayaris` in `content.js`. The Shayari section only appears once you add at least one.
5. Background music is the official YouTube video set in `music.youtubeId`. It starts when she taps "Enter Our Story" or the music button.
6. Open `index.html` in a browser to preview.

## Publish for free (GitHub Pages)

1. Create a public GitHub repository and push these files.
2. Go to **Settings → Pages → Source: Deploy from a branch → `main` / root**.
3. Your site will be live at `https://<username>.github.io/<repo>/`.
